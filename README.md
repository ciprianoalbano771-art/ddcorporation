# DDC Corporation

English-language static website with responsive CSS and an animated, realistic Earth image.

## Files

- `index.html`: complete website with CSS, JavaScript and the Earth image embedded.
- `vercel.json`: Vercel configuration.
- `README.md`: setup and deployment instructions.

## Deploy to Vercel

1. Place these three files in the root of your Git repository. Keep the page filename exactly `index.html`.
2. Import the repository into Vercel.
3. Select **Other** as the Framework Preset.
4. Keep the Root Directory at the repository root.
5. Leave the Build Command and Output Directory overrides disabled. No build step is required.
6. Click **Deploy**.

No packages, external image files or environment variables are required.

## Local preview

Open `index.html` in a modern browser.

## Contact form

The form prepares a message locally and offers a copy button. It does not send messages or save customer data. Official contact details still need to be added.

## Animation

The Earth image rotates continuously using CSS. The animation is disabled when the visitor has enabled reduced motion in their device settings.
